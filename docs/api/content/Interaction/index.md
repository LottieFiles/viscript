# Interaction

Lua UI, Input, Runtime and States work with objects already created in a Scene. Declare controls and definitions during loading; retained callbacks update the existing scene. These APIs require the optional interactive modules. JavaScript applications deliver input through the [host API](../Host/host-input.md).
