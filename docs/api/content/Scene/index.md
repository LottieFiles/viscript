# Scene

Build one root scene, add objects, and author its timeline. Geometry uses world units, time uses seconds, and angles use radians.

| Page | APIs |
| --- | --- |
| [Construction](./scene-construction.md) | Create a scene, configure its frame and camera, compile JavaScript. |
| [Object lifecycle](./scene-objects.md) | Find, clone, remove and measure objects. |
| [Timeline](./scene-timeline.md) | Wait, mark time, schedule callbacks and run parallel tracks. |
| [Camera](./scene-camera.md) | Move, orbit and focus the root camera. |
| [Viewports & transitions](./scene-viewports.md) | Compose completed child scenes and sequence stages. |
| [Views](./scene-views.md) | Create and animate additional views of the same scene. |
| [Trackers](./scene-trackers.md) | Bind object state to animated numeric values. |
| [Audio cues](./scene-audio.md) | Schedule sound and animate cue gain. |

Each page pairs its function reference with complete Markdown examples. Object constructors are under [Object](../Object/index.md); visual effects are under [Animation](../Animation/index.md).
