# Group & Space

Create containers for shared transforms and layout, or coordinate systems for mathematical scenes. Both inherit [Object factories and methods](../Object/index.md).

- [Group Layout & Selection](./group-layout.md) — Group creation, row/grid layout, and row/entry/column selection.
- [Spaces & Sampling](./spaces-sampling.md) — coordinate axes, tick labels, sampled cells, and voxels.

Selection methods for specialized Groups live beside their constructors: [Code Blocks & Search](../Object/code-blocks.md) and [Rich Text & TeX](../Object/rich-text-tex.md).
