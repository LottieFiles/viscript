<Hero>
# Explain ideas<br />in motion.

viscript turns code into animated explanations — algorithms, geometry, and graphics internals — natively or in the browser.
</Hero>

<Features>
<Feature title="Show every step, not just the result">
Sorting passes, graph searches, pixel sampling, rasterization: animate the intermediate states that static diagrams leave out.
</Feature>
<Feature title="Scenes as code, written with AI">
Describe a retained scene once in Lua or JavaScript, then animate it by changing properties. Bundled skills teach your coding agent to draft a scene, check its layout, and render it for you to refine.
</Feature>
<Feature title="Embed it where you need it">
Link the C library into a native app, load the WebAssembly runtime in a web page, or preview beside your code in VS Code. One Lua scene, one renderer.
</Feature>
</Features>
