# Themes

A theme supplies a scene's background, text styles, colour cycle, semantic colours, stroke width and axis colours.<br />
Colour names such as `"accent"` resolve through it, so changing `theme` restyles the whole scene.

## Presets

| Token | Appearance |
|---|---|
| `"pro_white"` | Light background; the default. |
| `"pro_black"` | Dark background. |
| `"adaptive"` | The colours of the app that shows the scene, light or dark; `pro_white` where there is none. |

The presets set `h1`, `h2`, `h3` and `text` in Pretendard and `code` in JetBrains Mono.

## Adaptive theme

`"adaptive"` takes its colours, and the font of `h1`, `h2`, `h3` and `text`, from the app that shows the scene.<br />
When the app switches between light and dark, the scene is drawn again in the new colours. Write it with semantic colours, and it fits wherever it is shown.

| Where | Colours | Headings and text | Follows |
|---|---|---|---|
| This site | The page's | Pretendard | The light/dark switch at the top right |
| VS Code | The editor theme's | Source Serif 4, Hangul in Pretendard | The editor theme |
| Obsidian | The Obsidian theme's | The plugin's text font | The Obsidian theme |
| CLI | `pro_white`'s | Pretendard | |

Switch this page between light and dark, and the scene below follows.

```lua live
local scene = vis.scene {
    width = 960, height = 540, theme = "adaptive",
    camera = {mode = "fixed", view = "2d", height = 6},
}

scene:text {text = "adaptive", role = "h2", point = {0, 2}}
local a = scene:circle {center = {-2.6, 0}, radius = 0.7}
local b = scene:rectangle {center = {0, 0}, size = {1.4, 1.4}, fill = "accent"}
local c = scene:circle {center = {2.6, 0}, radius = 0.7}
scene:text {text = "the page's colours, light or dark", point = {0, -1.8}, color = "muted", size = 20}

scene:create({a, b, c}, 0.6, "smooth", 0.1)
scene:indicate(b)

return scene
```

An app of your own gives the runtime its theme before it loads a scene. Colours it leaves out are the runtime's light or dark ones, and `font` is Pretendard when left out.

```js
runtime.hostTheme({dark: true, background: "#1e1e1e", accent: "#4daafc", font: "Source Serif 4, Pretendard"});
```

## Semantic colours

Any colour field takes a hex string or one of these roles:

| Role | Use |
|---|---|
| `background`, `foreground` | Canvas and primary content |
| `muted` | Secondary labels and structure |
| `accent`, `secondary` | Emphasis |
| `success`, `warning`, `danger`, `info` | Status |
| `surface`, `border` | Panels and boundaries |
| `result` | A derived value or output |
| `focus` | The current subject; `indicate` uses it |

Shapes with no colour take the next colour of the theme's `objects` cycle. Text takes font, size and colour from its `role`.

## Custom theme

Pass a table instead of a name. Fields you leave out come from `preset` (`pro_white` by default); `objects` replaces the colour cycle.

```lua live
local scene = vis.scene {
    width = 960, height = 540,
    camera = {mode = "fixed", view = "2d", height = 6},
    theme = {
        preset = "pro_black",
        background = "#10141c",
        objects = {"#f4a261", "#2a9d8f", "#e76f51"},
        colors = {accent = "#e9c46a", result = "#2a9d8f", focus = "#f4a261"},
        text = {h2 = {size = 34, color = "#e9c46a"}},
        object_width = 3,
    },
}

scene:text {text = "Custom theme", role = "h2", point = {0, 2}}
local a = scene:circle {center = {-3, 0}, radius = 0.8}
local b = scene:rectangle {center = {0, 0}, size = {1.6, 1.6}}
local c = scene:polygon {points = {{2.2, -0.8}, {3.8, -0.8}, {3, 0.8}}}
scene:text {text = "result", point = {0, -1.6}, color = "result", size = 22}

scene:create({a, b, c}, 0.8, "smooth", 0.15)
scene:indicate(b)

return scene
```

## Themes with viewports

A theme belongs to a scene, not to the page. Put scenes side by side with [viewports](#/docs/viewports), and each one draws in its own theme.

Below, one function builds the same card six times: the two presets and four custom themes.<br />
The uncoloured circles take each theme's `objects`, the bar its `accent`, the label its `result`, and `indicate` its `focus`.

```lua live
local root = vis.scene {width = 960, height = 540, theme = "pro_black",
                        camera = {mode = "fixed", view = "2d", height = 6}}

local function swatch(theme, name)
    local s = vis.scene {width = 320, height = 270, theme = theme,
                         camera = {mode = "fixed", view = "2d", height = 4}}
    s:text {text = name, role = "h3", point = {0, 1.45}}
    local shapes = {}
    for i, x in ipairs({-1.4, 0, 1.4}) do
        shapes[i] = s:circle {center = {x, 0.2}, radius = 0.45}
    end
    local bar = s:rectangle {center = {-0.5, -1.05}, size = {1.8, 0.3}, fill = "accent"}
    s:text {text = "result", point = {1.2, -1.05}, color = "result", size = 16}
    s:create(shapes, 0.6, "smooth", 0.1)
    s:grow_from_edge(bar, "left", 0.5)
    s:indicate(shapes[2])
    return s
end

local themes = {
    {"pro_white", "pro_white"},
    {"pro_black", "pro_black"},
    {{preset = "pro_white", background = "#fbf3e4", objects = {"#d1495b", "#edae49", "#00798c"},
      colors = {accent = "#d1495b", result = "#00798c", focus = "#30638e"}}, "paper"},
    {{preset = "pro_black", background = "#0b1d2e", objects = {"#4cc9f0", "#4895ef", "#b5e48c"},
      colors = {accent = "#4cc9f0", result = "#b5e48c", focus = "#f72585"}}, "ocean"},
    {{preset = "pro_black", background = "#14001f", objects = {"#ff00c8", "#00f0ff", "#faff00"},
      colors = {accent = "#00f0ff", result = "#faff00", focus = "#ff00c8"}, object_width = 3}, "neon"},
    {{preset = "pro_white", background = "#eeeeee", objects = {"#222222", "#666666", "#aaaaaa"},
      colors = {accent = "#222222", result = "#666666", focus = "#e63946"}}, "mono"},
}
for i, entry in ipairs(themes) do
    local column, row = (i - 1) % 3, (i - 1) // 3
    root:viewport(swatch(entry[1], entry[2]), {x = column / 3, y = row / 2, width = 1 / 3, height = 1 / 2})
end

return root
```

## Themes in animation

Emphasis effects colour themselves from the theme: `indicate`, `circumscribe`, `flash` and `ripple` use `focus` unless you pass `color`.<br />
Write the scene once with role names, and the same animation reads on any theme.

A scene's theme is set once, when the scene is made; it does not animate.

To change themes during a video, as below, make one scene per theme and play them with [`scene_transition`](#/docs/scene-transitions), which cross-fades from one to the next.<br />
Each child scene in a [viewport](#/docs/viewports) keeps its own theme.

```lua live
local cam = {mode = "fixed", view = "2d", height = 6}

local function scene_in(theme)
    local s = vis.scene {width = 960, height = 540, theme = theme, camera = cam}
    s:text {text = type(theme) == "string" and theme or "custom", role = "h3", point = {0, 2.2}}
    local a = s:circle {center = {-2.6, 0}, radius = 0.7}
    local b = s:rectangle {center = {0, 0}, size = {1.4, 1.4}}
    local c = s:circle {center = {2.6, 0}, radius = 0.7, fill = "result"}
    s:create({a, b, c}, 0.6, "smooth", 0.1)
    s:indicate(a)
    s:circumscribe(b)
    s:flash(c)
    return s
end

local root = vis.scene {width = 960, height = 540, theme = "pro_black", camera = cam}
root:scene_transition({
    scene_in("pro_white"),
    scene_in("pro_black"),
    scene_in({preset = "pro_black", colors = {focus = "#ff7a45", result = "#7ee787"}}),
}, {duration = 0.6, hold = 3.2, curve = "smooth"})

return root
```

```js live
    s.text({text: typeof theme === "string" ? theme : "custom", role: "h3", point: [0, 2.2]});
    const a = s.circle({center: [-2.6, 0], radius: 0.7});

    s.create([a, b, c], 0.6, "smooth", 0.1);
    s.indicate(a);
    s.circumscribe(b);
    s.flash(c);
    return s;
}

const root = vis.scene({width: 960, height: 540, theme: "pro_black", camera: cam});
root.sceneTransition([
    sceneIn("pro_white"),
    sceneIn("pro_black"),
    sceneIn({preset: "pro_black", colors: {focus: "#ff7a45", result: "#7ee787"}}),
], {duration: 0.6, hold: 3.2, curve: "smooth"});

return root;
```
