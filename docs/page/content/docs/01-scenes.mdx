# Scenes & Objects

Every script builds one scene. This page covers the scene itself; the pages below cover what goes in it.

## The root scene

### Create and return

Every script builds one root scene with `vis.scene`, adds objects to it, and **returns it**.<br />
The script runs once to *construct* the scene; the host then renders any time `t` from it.

```lua live
local scene = vis.scene {}
local dot = scene:circle {fill = "accent"}
scene:grow_from_center(dot, {duration = 0.6})

return scene
```

```js live
const scene = vis.scene();
const dot = scene.circle({fill: "accent"});
scene.growFromCenter(dot, {duration: 0.6});

return scene;
```

### Camera and world units

Objects are placed in world units, not pixels.<br />
The camera decides how much of the world fits in the frame: it shows six units vertically unless `camera.height` says otherwise, so a 960×540 frame spans about ±5.33 × ±3.

To pan and zoom during the scene, see [Camera](#/docs/camera).

```lua live
local scene = vis.scene {}

local axes = scene:space {x = {-5, 5, 1}, y = {-3, 3, 1}, stroke = "#00000000", ticks = true}
local dot = axes:circle {radius = 0.2, fill = "warning"}

scene:fade_in(axes, {duration = 0.4})
scene:shift(dot, {4, 2}, {duration = 1, curve = "smooth"})
scene:shift(dot, {-8, -4}, {duration = 1.2, curve = "smooth"})

return scene
```

```js live
const scene = vis.scene();

const axes = scene.space({x: [-5, 5, 1], y: [-3, 3, 1], stroke: "#00000000", ticks: true});
const dot = axes.circle({radius: 0.2, fill: "warning"});

scene.fadeIn(axes, {duration: 0.4});
scene.shift(dot, [4, 2], {duration: 1, curve: "smooth"});
scene.shift(dot, [-8, -4], {duration: 1.2, curve: "smooth"});

return scene;
```
