# Animation

The timeline cursor, curves, entrances and lag. The pages below cover transforms, composite play, text and morphing.

## The timeline cursor

<p>viscript records animation against a <strong>cursor</strong>. Each call adds a clip that starts at the cursor and moves the cursor to the
clip's end, so the order you write calls in is the order they play. <code>scene:wait(d)</code> simply advances the cursor.</p>
<p>Clips are tracked per property. A <code>shift</code> and a <code>fade</code> of the same object may overlap; two <code>shift</code>s may not.
Breaking that rule fails with an error that names it. Because the result is a plain timeline, any frame can be sampled directly — drag the
scrubber under the player.</p>
<p>The last argument picks the curve: a preset name, or a cubic Bézier.</p>
<table>
<tr><th>Curve</th><th>Shape</th><th>Feels like</th></tr>
<tr><td><code>"linear"</code></td><td>Constant speed</td><td>Mechanical; scanning, playheads</td></tr>
<tr><td><code>"smooth"</code></td><td>Smoothstep — slow, fast, slow (default)</td><td>General motion</td></tr>
<tr><td><code>"ease_in"</code></td><td>Starts slow, ends fast</td><td>Leaving the frame</td></tr>
<tr><td><code>"ease_out"</code></td><td>Starts fast, ends slow</td><td>Arriving, settling</td></tr>
<tr><td><code>"ease_in_out"</code></td><td>Quadratic in, then out</td><td>Moves between two rests</td></tr>
<tr><td><code>"gentle"</code></td><td>Smootherstep — softer ends than <code>smooth</code></td><td>Camera moves, slow reveals</td></tr>
<tr><td><code>"snappy"</code></td><td>Quick start, long settle</td><td>UI-like responses</td></tr>
<tr><td><code>"back"</code></td><td>Overshoots the target, then returns</td><td>Playful arrivals</td></tr>
<tr><td><code>"bounce"</code></td><td>Bounces against the target</td><td>Dropping, landing</td></tr>
<tr><td><code>"elastic"</code></td><td>Springs past the target and rings out</td><td>Emphasis, springs</td></tr>
<tr><td><code>&#123;bezier = &#123;x1, y1, x2, y2&#125;&#125;</code></td><td>Custom cubic Bézier (as in CSS); <code>x</code> in 0–1</td><td>Anything else</td></tr>
</table>
<p>Below, every curve moves a dot the same distance in the same two seconds; <code>parallel</code> starts them together.</p>

```lua live
local scene = vis.scene {
    width = 960, height = 540, theme = "pro_black",
    camera = {mode = "fixed", view = "2d", height = 6},
}

local curves = {"linear", "smooth", "ease_in", "ease_out", "ease_in_out",
                "gentle", "snappy", "back", "bounce", "elastic",
                {bezier = {0.7, -0.4, 0.3, 1.4}}}
local moves = {}
for i, curve in ipairs(curves) do
    local y = 2.5 - (i - 1) * 0.5
    local name = type(curve) == "string" and curve or "bezier"
    scene:text {text = name, point = {-2.4, y}, align = {1, 0.5}, size = 15,
                font = "JetBrainsMono", color = "muted"}
    scene:line {from = {-2, y}, to = {4, y}, stroke = "muted", width = 1, opacity = 0.3}
    local dot = scene:circle {center = {-2, y}, radius = 0.13, fill = "accent"}
    moves[i] = function() scene:shift(dot, {6, 0}, 2, curve) end
end

scene:wait(0.3)
scene:parallel(table.unpack(moves))
scene:wait(0.8)

return scene
```

```js live
const scene = vis.scene({
    width: 960, height: 540, theme: "pro_black",
    camera: {mode: "fixed", view: "2d", height: 6},
});

const curves = ["linear", "smooth", "ease_in", "ease_out", "ease_in_out",
                "gentle", "snappy", "back", "bounce", "elastic",
                {bezier: [0.7, -0.4, 0.3, 1.4]}];
const moves = curves.map((curve, i) => {
    const y = 2.5 - i * 0.5;
    const name = typeof curve === "string" ? curve : "bezier";
    scene.text({text: name, point: [-2.4, y], align: [1, 0.5], size: 15,
                font: "JetBrainsMono", color: "muted"});
    scene.line({from: [-2, y], to: [4, y], stroke: "muted", width: 1, opacity: 0.3});
    const dot = scene.circle({center: [-2, y], radius: 0.13, fill: "accent"});
    return () => scene.shift(dot, [6, 0], 2, curve);
});

scene.wait(0.3);
scene.parallel(...moves);
scene.wait(0.8);

return scene;
```

## Entrances and emphasis

<p>Entrances hide their target until their scheduled start; objects without one are visible from <code>t = 0</code>.</p>
<table>
<tr><th>Call</th><th>Effect</th><th>Best for</th></tr>
<tr><td><code>create</code></td><td>Draws the stroke on</td><td>Lines, outlines, plots</td></tr>
<tr><td><code>draw_border_then_fill</code></td><td>Outline, then fill fades in</td><td>Filled shapes</td></tr>
<tr><td><code>fade_in</code></td><td>Fades, optional <code>shift</code>/<code>scale</code></td><td>Anything</td></tr>
<tr><td><code>grow_from_center</code> / <code>grow_from_edge</code></td><td>Reveals by size</td><td>Bars, boxes</td></tr>
<tr><td><code>indicate</code></td><td>Brief scale + recolour</td><td>Emphasis</td></tr>
</table>

```lua live
local scene = vis.scene {
    width = 960, height = 540, theme = "pro_black",
    camera = {mode = "fixed", view = "2d", height = 6},
}

-- one slot per call: the label is there from t = 0, the shape enters on its turn
local function slot(x, y, name)
    scene:text {text = name, point = {x, y - 1}, align = {0.5, 0.5}, size = 14,
                font = "JetBrainsMono", color = "muted"}
end
slot(-3.4, 1.3, "create");           slot(0, 1.3, "draw_border_then_fill")
slot(3.4, 1.3, "fade_in");          slot(-3.4, -1.5, "grow_from_center")
slot(0, -1.5, "grow_from_edge");    slot(3.4, -1.5, "indicate")

local ring = scene:circle {center = {-3.4, 1.3}, radius = 0.6, stroke = "accent", width = 4}
local box = scene:rectangle {center = {0, 1.3}, size = {1.3, 1.1}, corner = 0.15, fill = "secondary"}
local card = scene:rectangle {center = {3.4, 1.3}, size = {1.2, 1.1}, corner = 0.15, fill = "success"}
local dot = scene:circle {center = {-3.4, -1.5}, radius = 0.55, fill = "warning"}
local bar = scene:rectangle {center = {0, -1.5}, size = {1.6, 0.5}, fill = "info"}
local star = scene:circle {center = {3.4, -1.5}, radius = 0.45, fill = "accent"}

scene:create(ring, 0.8)
scene:draw_border_then_fill(box, 2)
scene:fade_in(card, {shift = {0, -0.4}, duration = 0.6})
scene:grow_from_center(dot, 0.6)
scene:grow_from_edge(bar, "left", 0.7)
scene:indicate(star, {color = "danger", scale = 1.4, duration = 0.8})
scene:wait(0.6)

return scene
```


### Staggering with lag

Pass an array and a fourth argument, `lag`, to start each item that many seconds after the previous one. The whole span is `duration + lag × (n − 1)` — here `0.8 + 0.2 × 5 = 1.8` s for the lower row.

```lua live
local scene = vis.scene {
    width = 960, height = 540, theme = "pro_black",
    camera = {mode = "fixed", view = "2d", height = 6},
}

local together, staggered = {}, {}
for i = 1, 6 do
    local x = -4.5 + i * 1.3
    together[i] = scene:circle {center = {x, 1}, radius = 0.4, fill = "accent"}
    staggered[i] = scene:circle {center = {x, -1}, radius = 0.4, fill = "warning"}
end

scene:draw_border_then_fill(together, 0.8)              -- lag 0: all at once
scene:draw_border_then_fill(staggered, 0.8, "smooth", 0.2)  -- each starts 0.2 s later
scene:wait(0.5)

return scene
```

```js live
const scene = vis.scene({
    width: 960, height: 540, theme: "pro_black",
    camera: {mode: "fixed", view: "2d", height: 6},
});

const together = [], staggered = [];
for (let i = 1; i <= 6; i++) {
    const x = -4.5 + i * 1.3;
    together.push(scene.circle({center: [x, 1], radius: 0.4, fill: "accent"}));
    staggered.push(scene.circle({center: [x, -1], radius: 0.4, fill: "warning"}));
}

scene.drawBorderThenFill(together, 0.8);              // lag 0: all at once
scene.drawBorderThenFill(staggered, 0.8, "smooth", 0.2);  // each starts 0.2 s later
scene.wait(0.5);

return scene;
```
