# Text and labels

## Text

`text` draws a string at a world point. Set `size` in points, or pick a `role` and let the theme size it. `write` reveals it stroke by stroke.

```lua live
local scene = vis.scene {}

local title = scene:text {text = "Heading", role = "h1", point = {0, 1.2}}
local body = scene:text {text = "Body text sized by the theme", role = "text", point = {0, 0}}
local code = scene:text {text = "Monospace for code", font = "JetBrainsMono", size = 22,
                         color = "warning", point = {0, -1.1}}

scene:write(title, 0.8)
scene:write(body, 0.8)
scene:write(code, 0.8)

return scene
```

```js live
const scene = vis.scene();

const title = scene.text({text: "Heading", role: "h1", point: [0, 1.2]});

                         color: "warning", point: [0, -1.1]});

scene.write(title, 0.8);
scene.write(body, 0.8);
scene.write(code, 0.8);

return scene;
```

## Alignment

`point` is an anchor, and `align` says which part of the text sits on it: `0` is left/bottom, `0.5` the centre, `1` right/top. Here all three lines anchor on the same vertical line.

```lua live
local scene = vis.scene {}

local guide = scene:line {from = {0, -2}, to = {0, 2}, stroke = "muted", width = 1, dash = {6, 6}}
local left = scene:text {text = "align {0, 0.5}", point = {0, 1}, align = {0, 0.5}, size = 22}
local mid = scene:text {text = "align {0.5, 0.5}", point = {0, 0}, align = {0.5, 0.5}, size = 22}
local right = scene:text {text = "align {1, 0.5}", point = {0, -1}, align = {1, 0.5}, size = 22}

scene:create(guide, 0.4)
scene:fade_in(left, {duration = 0.4})
scene:fade_in(mid, {duration = 0.4})
scene:fade_in(right, {duration = 0.4})

return scene
```

```js live
const scene = vis.scene();

const guide = scene.line({from: [0, -2], to: [0, 2], stroke: "muted", width: 1, dash: [6, 6]});
const left = scene.text({text: "align {0, 0.5}", point: [0, 1], align: [0, 0.5], size: 22});
const mid = scene.text({text: "align {0.5, 0.5}", point: [0, 0], align: [0.5, 0.5], size: 22});
const right = scene.text({text: "align {1, 0.5}", point: [0, -1], align: [1, 0.5], size: 22});

scene.create(guide, 0.4);
scene.fadeIn(left, {duration: 0.4});
scene.fadeIn(mid, {duration: 0.4});
scene.fadeIn(right, {duration: 0.4});

return scene;
```

## Labels

`object:label` creates the same text as a **child** of an object, so it moves with it. `scene:text` stays where you put it.

```lua live
local scene = vis.scene {}

local dot = scene:circle {center = {-3, 0}, radius = 0.5, fill = "accent"}
dot:label {text = "label", point = {-3, -0.9}, align = {0.5, 1}, size = 20, layer = 2}
local fixed = scene:text {text = "text", point = {-3, 1}, align = {0.5, 0}, size = 20, color = "muted"}

scene:grow_from_center(dot, 0.4)
scene:shift(dot, {6, 0}, 1.4, "ease_in_out")  -- the label follows, the text stays

return scene
```

```js live
const scene = vis.scene();

const dot = scene.circle({center: [-3, 0], radius: 0.5, fill: "accent"});
dot.label({text: "label", point: [-3, -0.9], align: [0.5, 1], size: 20, layer: 2});
const fixed = scene.text({text: "text", point: [-3, 1], align: [0.5, 0], size: 20, color: "muted"});

scene.growFromCenter(dot, 0.4);
scene.shift(dot, [6, 0], 1.4, "ease_in_out");  // the label follows, the text stays

return scene;
```

## TeX

`tex` typesets math in the scene's fonts. `tex` takes a TeX string, or a list of parts; each part becomes its own group, so `part(tex)` can find it later to colour or animate.

The result is an ordinary group of glyphs and shapes, and it places like `text`: `point`, `align`, `size` or `role`.

`part(tex, n)` finds the nth part, or else glyph, whose TeX matches, ignoring spaces.

Split a formula into parts to keep terms together when you colour them or `match_transform` one formula into another.

Write `\\` for a backslash inside a quoted string.<br />
`tex` comes from the TeX module: the WASM runtime includes it, and a native build needs `-Dmodules=tex`.

```lua live
local scene = vis.scene {}

local identity = scene:tex {tex = "e^{i\\pi} + 1 = 0", point = {0, 1.2}, role = "h2"}
local pythagoras = scene:tex {
    tex = {"a^2", "+", {"b^2", color = "warning"}, "=", {"c^2", id = "hyp"}},
    point = {0, -0.6}, role = "h2",
}
local inline = scene:tex {tex = "\\sum_{k=1}^{n} k = \\frac{n(n+1)}{2}", display = false,
                          point = {0, -2}, size = 22, color = "muted"}

scene:write(identity, 1)
scene:write(pythagoras, 1)
scene:tween({target = pythagoras:part("c^2"), fill = "accent"}, 0.5)
scene:fade_in(inline, {duration = 0.5})

return scene
```

```js live
const scene = vis.scene();

const identity = scene.tex({tex: "e^{i\\pi} + 1 = 0", point: [0, 1.2], role: "h2"});
const pythagoras = scene.tex({
    tex: ["a^2", "+", {text: "b^2", color: "warning"}, "=", {text: "c^2", id: "hyp"}],
    point: [0, -0.6], role: "h2",
});
const inline = scene.tex({tex: "\\sum_{k=1}^{n} k = \\frac{n(n+1)}{2}", display: false,
                          point: [0, -2], size: 22, color: "muted"});

scene.write(identity, 1);
scene.write(pythagoras, 1);
scene.tween({target: pythagoras.part("c^2"), fill: "accent"}, 0.5);
scene.fadeIn(inline, {duration: 0.5});

return scene;
```

## Code

`code` lays out source as coloured tokens in the theme's monospaced font.

It returns a group whose children are the lines, and each line's children are its tokens, so `row(n)` picks a line and `search` picks tokens.

Code holds only text, so shape options such as `fill` or `stroke` are rejected. Token IDs read `<block-id>/<line>/<token>`.

```lua live
local scene = vis.scene {}

local listing = scene:code {
    text = "local total = 0\nfor i = 1, 10 do\n    total = total + i\nend\nreturn total",
    language = "lua", point = {0, 0}, align = {0.5, 0.5}, size = 22, id = "listing",
}

scene:write(listing, 1.2)
scene:highlight(listing, listing:search("total", {match = "all", whole = true}))
scene:wait(0.6)
scene:highlight(listing)
listing = scene:edit(listing, {replace = "total", with = "sum", match = "all", whole = true}, 1)

return scene
```

```js live
const scene = vis.scene();

let listing = scene.code({
    text: "local total = 0\nfor i = 1, 10 do\n    total = total + i\nend\nreturn total",
    language: "lua", point: [0, 0], align: [0.5, 0.5], size: 22, id: "listing",
});

scene.write(listing, 1.2);
scene.highlight(listing, listing.search("total", {match: "all", whole: true}));
scene.wait(0.6);
scene.highlight(listing);
listing = scene.edit(listing, {replace: "total", with: "sum", match: "all", whole: true}, 1);

return scene;
```

| Call | Does |
|---|---|
| `block:row(n)` | The nth line, from 1. |
| `block:search(find, {match, lines, whole})` | Tokens a string or pattern covers; `match` is `"first"`, `"last"`, `"all"` or an occurrence number. |
| `scene:highlight(block, selection)` | Dims everything but the selected lines or tokens; no selection restores the block. |
| `scene:edit(block, edits, duration)` | Returns the edited block and animates the diff. Edits: `replace`/`with`, `insert` + `before`/`after`, `remove`, `append`, `prepend`. |

## Matrices and tables

`matrix` and `table` lay out rows of numbers or strings.

In a `matrix`, a string entry is TeX: `"\\cos\\theta"` or `"x^2"` is set as inline math, as a cell of a TeX matrix is, while numbers stay texts that `tween {value = ...}` can count. Without the TeX module, string entries fall back to plain text.

A `table` always sets strings as text.

Like `code`, they return a group of row groups, so `row(r)`, `entry(r, c)` and `column(c)` pick parts, counting from 1.<br />
A matrix adds brackets; a table adds an optional header, stripes and rules.

`row(r)` counts only rows: a table's header is not a row, and its stripes and rules are extra children of the group.

```lua live
local scene = vis.scene {}

local m = scene:matrix {rows = {{"\\cos\\theta", "-\\sin\\theta", 0}, {"\\sin\\theta", "\\cos\\theta", 0}, {0, 0, 1}},
                        point = {-3, 0}, brackets = "square", size = 24}
local t = scene:table {
    header = {"op", "cost"},
    rows = {{"read", 1}, {"write", 4}, {"sort", 12}},
    point = {2.8, 0}, justify = {"left", "right"}, stripes = true, size = 22,
}

scene:fade_in(m, {duration = 0.5})
scene:fade_in(t, {duration = 0.5})
scene:indicate(m:column(2))
scene:indicate(t:entry(3, 2))

return scene
```

```js live
const scene = vis.scene();

const m = scene.matrix({rows: [["\\cos\\theta", "-\\sin\\theta", 0], ["\\sin\\theta", "\\cos\\theta", 0], [0, 0, 1]],
                        point: [-3, 0], brackets: "square", size: 24});
const t = scene.table({
    header: ["op", "cost"],
    rows: [["read", 1], ["write", 4], ["sort", 12]],

});
```
